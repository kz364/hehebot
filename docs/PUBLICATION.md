# Hehebot publication status

The private repository contains the control plane, Codex 0.154.0 execution boundary, provider/lifecycle components, portal, Electron shell, contracts, tests, and current documentation. Publishing source does not deploy Hehebot or enable execution.

Excluded: credentials, OAuth/connector state, personal profiles and exports, local databases/browser state, raw logs, dependencies, and build caches. Each installation must authorize its own accounts.

Use `bash scripts/verify-codex.sh` and the desktop commands in `README.md` for current evidence. Scripted fixtures and dry-run builds do not establish authenticated inference, production readiness, live provider/connector behavior, recursive settlement, Mac acceptance, or legal/security certification. Production gates remain false.
